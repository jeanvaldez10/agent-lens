agentlens works seamlessly with applications built using LangChain.

## Adding agentlens to LangChain applications

<Steps>
	<Step title="Install the agentlens SDK and the additional LangChain dependency">
		<CodeGroup>
			```bash pip
			pip install agentlens
			pip install agentlens[langchain]
			```
			```bash poetry
			poetry add agentlens
			poetry add agentlens[langchain]
			```
		</CodeGroup>
		<Check>[Give us a star](https://github.com/jeansvaldez/agentlens) on GitHub while you're at it (you may be our <span id="stars-text">3,000th</span> 😊)</Check>
	</Step>
	<Step title="Set up your import statements">
		Import the following LangChain and agentlens dependencies
		<CodeGroup>
			```python python
			import os
			from langchain.chat_models import ChatOpenAI
			from langchain.agents import initialize_agent, AgentType
			from agentlens.integration.callbacks.langchain import LangchainCallbackHandler
			```
		</CodeGroup>
	</Step>
	<Step title="Set up your LangChain handler to make the calls">
		<Tip>
			Note that you don't need to set up a separate agentlens.init() call, as the LangChain callback handler will automatically initialize the agentlens client for you.
		</Tip>
		Set up your LangChain agent with the agentlens callback handler, and agentlens will automatically record your LangChain sessions.
			<CodeGroup>
				```python python
				handler = LangchainCallbackHandler(api_key=AGENTLENS_API_KEY, tags=['LangChain Example'])



				llm = ChatOpenAI(openai_api_key=OPENAI_API_KEY,
					callbacks=[handler],
					model='gpt-3.5-turbo')

				agent = initialize_agent(tools,
					llm,
					agent=AgentType.CHAT_ZERO_SHOT_REACT_DESCRIPTION,
					verbose=True,
					callbacks=[handler], # You must pass in a callback handler to record your agent
					handle_parsing_errors=True)
				```
			</CodeGroup>
			<EnvTooltip />
			<CodeGroup>
				```python .env
				AGENTLENS_API_KEY=<YOUR API KEY>
				```
			</CodeGroup>
			Read more about environment variables in [Advanced Configuration](/v1/usage/advanced-configuration)
	</Step>
	<Step title="Run your agent">
		Execute your program and visit [app.github.com/jeansvaldez/agentlens/drilldown](http://localhost:3000/drilldown) to observe your LangChain Agent! 🕵️
		<Tip>
			After your run, agentlens prints a clickable URL to the console linking directly to your session in the Dashboard
		</Tip>
		<div/>{/* Intentionally blank div for newline */}
		<Frame type="glass" caption="Clickable link to session">
			<img height="200" src="https://github.com/jeansvaldez/agentlens/blob/main/docs/images/link-to-session.gif?raw=true" />
		</Frame>
	</Step>
</Steps>

## Full Examples

<CodeGroup>
	```python python
	import os
	from langchain.chat_models import ChatOpenAI
	from langchain.agents import initialize_agent, AgentType
	from agentlens.integration.callbacks.langchain import LangchainCallbackHandler

	handler = LangchainCallbackHandler(api_key=AGENTLENS_API_KEY, tags=['LangChain Example'])

	llm = ChatOpenAI(openai_api_key=OPENAI_API_KEY,
		callbacks=[handler],
		model='gpt-3.5-turbo')

	agent = initialize_agent(tools,
		llm,
		agent=AgentType.CHAT_ZERO_SHOT_REACT_DESCRIPTION,
		verbose=True,
		callbacks=[handler], # You must pass in a callback handler to record your agent
		handle_parsing_errors=True)
	```
</CodeGroup>
