[MultiOn](https://www.multion.ai) is a platform for building autonomous agents.

## Adding agentlens to MultiOn agents

<Steps>
	<Step title="Install MultiOn">
		<CodeGroup>
			```bash pip
			pip install -U multion
			```
			```bash poetry
			poetry add multion
			```
		</CodeGroup>
	</Step>
	<Step title="Create your API keys">
		* Create an [agentlens API key](http://localhost:3000/settings/projects)
		* Create a [MultiOn API key](https://app.multion.ai/api-keys)
	</Step>
	<Step title="Create a MultiOn client with an agentlens key">
		<CodeTooltip/>
			<CodeGroup>
				```python python
				import multion
				from multion.client import MultiOn
				
				# Initialize MultiOn with both a MultiOn API key and an agentlens API key
				multion = MultiOn(
					api_key=<INSERT YOUR MULTION API KEY HERE>,
					agentlens_api_key=<INSERT YOUR AGENTLENS API KEY HERE>
				)

				browse_response = multion.browse(
					cmd="what three things do i get with agentlens",
					url="https://www.github.com/jeansvaldez/agentlens/",
					max_steps=4,
					include_screenshot=True
				)

					print(browse_response.message)
					```
			</CodeGroup>		
		<EnvTooltip />
	</Step>
	<Step title="Run your agent">
		Execute your program and visit [app.github.com/jeansvaldez/agentlens/drilldown](http://localhost:3000/drilldown) to observe your MultiOn Agent! 🕵️
		<Tip>
			After your run, agentlens prints a clickable url to console linking directly to your session in the Dashboard
		</Tip>
		<div/>{/* Intentionally blank div for newline */}
		<Frame type="glass" caption="Clickable link to session">
		</Frame>
	</Step>
</Steps>
