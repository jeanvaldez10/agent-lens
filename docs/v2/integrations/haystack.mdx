[Haystack](https://docs.haystack.deepset.ai/docs/installation) is a flexible framework for building production-ready AI agents. agentlens makes monitoring your Haystack agents seamless.

## Installation

<CodeGroup>
```bash pip
pip install agentlens haystack-ai python-dotenv
```
```bash poetry
poetry add agentlens haystack-ai python-dotenv
```
```bash uv
uv pip install agentlens haystack-ai python-dotenv
```
</CodeGroup>

<Warning>
We currently only support Haystack 2.x.
</Warning>

## Setting Up API Keys

You'll need API keys for agentlens and whatever model provider you use with Haystack (e.g. OpenAI):

- **AGENTLENS_API_KEY**: From your [agentlens Dashboard](http://localhost:3000/)
- **OPENAI_API_KEY**: From the [OpenAI Platform](https://platform.openai.com/api-keys) *(if using OpenAI models)*

Set these as environment variables or in a `.env` file.

<CodeGroup>
```bash Export to CLI
export AGENTLENS_API_KEY="your_agentlens_api_key_here"
export OPENAI_API_KEY="your_openai_api_key_here"
```
```txt Set in .env file
AGENTLENS_API_KEY="your_agentlens_api_key_here"
OPENAI_API_KEY="your_openai_api_key_here"
```
</CodeGroup>

Then load them in your Python code:

```python
from dotenv import load_dotenv
import os

load_dotenv()
AGENTLENS_API_KEY = os.getenv("AGENTLENS_API_KEY")
OPENAI_API_KEY = os.getenv("OPENAI_API_KEY")
```

## Usage

Integrating agentlens with Haystack only takes a few lines:

```python
import agentlens
from haystack.components.generators.openai import OpenAIGenerator

agentlens.init(AGENTLENS_API_KEY)

generator = OpenAIGenerator(model="gpt-4o-mini", api_key=OPENAI_API_KEY)
result = generator.run(prompt="In one sentence, what is agentlens?")
print(result["replies"][0])
```

Run your script and visit the [agentlens Dashboard](http://localhost:3000/drilldown) to monitor the trace.
