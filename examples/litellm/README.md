# LiteLLM Examples with agentlens

This directory contains examples of using LiteLLM with agentlens instrumentation.

## Prerequisites

- Python >= 3.10 < 3.13
- Install required dependencies:
  ```
  pip install agentlens litellm
  ```

## Examples

### 1. LiteLLM Example

Example: `litellm_example`
This example demonstrates:
- Multi-provider LLM access through LiteLLM

## agentlens Integration

These examples show how to use agentlens to monitor and analyze your AI applications. agentlens automatically instruments your LiteLLM calls to provide insights into performance, usage patterns, and model behavior.

To learn more about agentlens, visit [https://www.github.com/jeanvaldez10/agent-lens](https://www.github.com/jeanvaldez10/agent-lens)
