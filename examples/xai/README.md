# xAI Examples with agentlens

This directory contains examples of using the xAI (Grok) API with agentlens instrumentation.

## Prerequisites

- Python >= 3.10 < 3.13
- Install required dependencies:
  ```
  pip install agentlens openai
  ```

## Examples

### 1. Grok Examples

Example: `grok_examples`
This example demonstrates:
- Basic Grok API usage

### 2. Grok Vision Examples

Example: `grok_vision_examples`

This example demonstrates:
- Vision capabilities with Grok

## agentlens Integration

These examples show how to use agentlens to monitor and analyze your AI applications. agentlens automatically instruments your xAI calls to provide insights into performance, usage patterns, and model behavior.

To learn more about agentlens, visit [https://www.github.com/jeansvaldez/agentlens](https://www.github.com/jeansvaldez/agentlens)
