# AG2 Examples with agentlens

This directory contains examples of using AG2 (AutoGen 2.0) with agentlens instrumentation for various multi-agent conversation tasks.

## Prerequisites

- Python >= 3.10 < 3.13
- Install required dependencies:
  ```
  pip install agentlens ag2
  ```

## Examples

### 1. Asynchronous Human Input

Example: `async_human_input`

This example demonstrates:
- Asynchronous human input handling

### 2. Wikipedia Search Tool

Example: `tools_wikipedia_search`

This example demonstrates:
- Wikipedia search tool integration

## agentlens Integration

These examples show how to use agentlens to monitor and analyze your AI applications. agentlens automatically instruments your AG2 calls to provide insights into performance, usage patterns, and model behavior.

To learn more about agentlens, visit [https://www.github.com/jeanvaldez10/agent-lens](https://www.github.com/jeanvaldez10/agent-lens)
