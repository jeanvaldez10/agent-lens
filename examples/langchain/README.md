# LangChain Examples with agentlens

This directory contains examples of using LangChain with agentlens instrumentation.

## Prerequisites

- Python >= 3.10 < 3.13
- Install required dependencies:
  ```
  pip install agentlens langchain langchain_openai
  ```

## Examples

### 1. LangChain Examples

Example: `langchain_examples`

## agentlens Integration

These examples show how to use agentlens to monitor and analyze your AI applications. agentlens automatically instruments your LangChain calls to provide insights into performance, usage patterns, and model behavior.

To learn more about agentlens, visit [https://www.github.com/jeansvaldez/agentlens](https://www.github.com/jeansvaldez/agentlens)
