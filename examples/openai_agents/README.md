# OpenAI Agents Examples with agentlens

This directory contains examples of using the OpenAI Agents SDK with agentlens instrumentation.

## Prerequisites

- Python >= 3.10 < 3.13
- Install required dependencies:
  ```
  pip install agentlens openai-agents
  ```

## Examples

### 1. Agent Patterns

Example: `agent_patterns`
This example demonstrates:
- Common agent design patterns

### 2. Agent Tools

Example: `agents_tools`

This example demonstrates:
- Agent tool integration

### 3. Customer Service Agent

Example: `customer_service_agent`

This example demonstrates:
- Customer service automation

## agentlens Integration

These examples show how to use agentlens to monitor and analyze your AI applications. agentlens automatically instruments your OpenAI Agents calls to provide insights into performance, usage patterns, and model behavior.

To learn more about agentlens, visit [https://www.github.com/jeanvaldez10/agent-lens](https://www.github.com/jeanvaldez10/agent-lens)
