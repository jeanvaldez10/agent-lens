# Google ADK Examples with agentlens

This directory contains examples of using the Google AI Development Kit (ADK) with agentlens instrumentation.

## Prerequisites

- Python >= 3.10 < 3.13
- Install required dependencies:
  ```
  pip install agentlens google-adk
  ```

## Examples

### 1. Human Approval

Example: `human_approval`
This example demonstrates:
- A human-in-the-loop approval workflow

## agentlens Integration

These examples show how to use agentlens to monitor and analyze your AI applications. agentlens automatically instruments your Google ADK calls to provide insights into performance, usage patterns, and model behavior.

To learn more about agentlens, visit [https://www.github.com/jeansvaldez/agentlens](https://www.github.com/jeansvaldez/agentlens)
