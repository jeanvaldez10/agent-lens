# AutoGen Examples with agentlens

This directory contains examples of using Microsoft AutoGen with agentlens instrumentation for various agent-based tasks.

## Prerequisites

- Python >= 3.10 < 3.13
- Install required dependencies:
  ```
  pip install agentlens "ag2[retrievechat]"
  ```

## Examples

### 1. Agent Chat

Example: `AgentChat`
This example demonstrates:
- Basic agent chat functionality

### 2. Math Agent

Example: `MathAgent`

This example demonstrates:
- A mathematical problem-solving agent

## agentlens Integration

These examples show how to use agentlens to monitor and analyze your AI applications. agentlens automatically instruments your AutoGen calls to provide insights into performance, usage patterns, and model behavior.

To learn more about agentlens, visit [https://www.github.com/jeansvaldez/agentlens](https://www.github.com/jeansvaldez/agentlens)
